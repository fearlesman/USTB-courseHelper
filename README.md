# USTB-courseHelper

面向 `byyt.ustb.edu.cn` 的北京科技大学选课辅助图形脚本。当前支持体育课以外的课程查询、课程列表缓存和定时选课。

## 运行环境

- Python 3.12（已使用该版本验证）
- Chrome 浏览器
- Selenium 4.35.0（使用内置 Selenium Manager 自动匹配 ChromeDriver）

安装依赖：

```bash
pip install orjson requests selenium selenium-wire pillow beautifulsoup4 pytest
```

启动程序：

```bash
python USTB-courseHelper.py
```

## ChromeDriver 自动匹配

登录时程序会交由 Selenium Manager 自动识别已安装的 Chrome 主版本，并下载或复用缓存中匹配的 ChromeDriver。项目不再使用 `drivers/` 中的固定驱动，因此 Chrome 自动更新后不会继续误用旧版本驱动。

首次登录或 Chrome 主版本升级后需要能访问 Chrome for Testing 下载源；匹配成功的驱动会缓存到当前用户的 Selenium 缓存目录，后续登录无需重复下载。若自动匹配失败，界面会显示原始错误信息；请确认 Chrome 已安装，并检查网络、代理或下载源访问情况。

## 学年学期（xnxq）

课程页面的“学期”输入框会在启动时按当天日期自动填充，格式为 `YYYY-YYYY-N`，仍可手动修改。

| 日期范围 | 以 2025 年为例 | 自动值 |
| --- | --- | --- |
| 1 月 1 日至 5 月 31 日 | 2025-01-01 至 2025-05-31 | `2024-2025-2` |
| 6 月 1 日至 7 月 27 日 | 2025-06-01 至 2025-07-27 | `2024-2025-3` |
| 7 月 28 日至 12 月 31 日 | 2025-07-28 至 2025-12-31 | `2025-2026-1` |

## 课程联合查询

课程页面支持“课程代码、课程名称”的联合筛选，至少填写一项。查询请求会同时使用 `p_kcdm_cxrw` 和 `p_gjz`；课程类别仅用于展示，不作为筛选条件。

查询结果会递归剔除 `null`、空文本、空列表和空对象，保留 `0` 与 `false`。结果表字段与接口字段的映射如下：

| 展示列 | 接口字段 |
| --- | --- |
| 展示名称 | `rwmc`，缺失时回退 `kcmc` |
| 课程代码、课程名称 | `kcdm`、`kcmc` |
| 课程性质、课程类别 | `kcxzmc`、`kclbmc` |
| 授课语言、计分方式 | `skyymc`、`jfzlbmc`，缺失时回退 `jfxs` |
| 学分、学时、上课信息 | `xf`、`zxs`、`kcxx` 中的青色标签 |
| 容量/已选、开课学院、校区 | `zrl/yxzrs`、`kkyxmc`、`xiaoqumc` |

课程类型默认选择“所有”，会分别查询素质扩展课、专业扩展课、MOOC 和必修课，并按任务 ID 去重合并结果。查询不会自动加入抢课列表。请在结果表中选中课程后点击“添加选中课程”；请求默认每页仅获取 17 条结果，避免无筛选或宽泛筛选产生过大的响应。

## 抢课模式

“轮询模式”会立即开始轮询。“定时抢课”被选中时才会显示抢课时间输入框；到达指定时间后，定时任务会进入与轮询模式相同的持续轮询流程。若设定时间已到或已过，会立即开始轮询，不会等待到次日。

## 验证

执行全部单元测试：

```bash
python -m pytest tests -q
```

### 验收场景

```gherkin
功能: 自动设置学年学期
  场景: 春季学期
    假如 当前日期为 2025-05-31
    当 应用初始化课程页面
    那么 学期输入框应为 2024-2025-2

  场景: 暑期学期边界
    假如 当前日期为 2025-07-27
    当 计算学年学期
    那么 结果应为 2024-2025-3

  场景: 秋季学期起始日
    假如 当前日期为 2025-07-28
    当 计算学年学期
    那么 结果应为 2025-2026-1

功能: 自动匹配 ChromeDriver
  场景: Chrome 更新后首次登录
    假如 本机 Chrome 主版本为 150 且缓存中不存在匹配驱动
    当 用户启动登录
    那么 Selenium Manager 下载并使用 Chrome 150 的匹配驱动

  场景: 自动匹配失败
    假如 ChromeDriver 下载服务不可访问
    当 用户启动登录
    那么 界面显示包含原始原因的中文诊断错误

功能: 课程联合查询
  场景: 代码与名称联合筛选
    假如 已登录且填写课程代码和课程名称
    当 用户点击查询课程
    那么 请求同时包含两个对应筛选参数并展示匹配课程

  场景: 默认查询所有课程类型
    假如 已登录且课程类型为所有
    当 用户点击查询课程
    那么 应用查询四种选课方式并合并去重结果

  场景: 防止过大响应
    假如 课程代码和课程名称都为空
    当 用户点击查询课程
    那么 应用提示至少填写一个条件且不发送请求

功能: 定时抢课
  场景: 到达抢课时间后持续轮询
    假如 用户选择定时抢课并设置未来时间
    当 到达设定时间
    那么 应用进入与轮询模式相同的持续抢课流程

  场景: 非定时模式隐藏时间字段
    假如 用户选择轮询模式
    那么 抢课时间输入框不显示
```

## 限制

体育课的请求参数尚未维护。项目不提供打包版本，登录流程请通过源码运行。
