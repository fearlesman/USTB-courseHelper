# USTB Course Helper

北京科技大学选课辅助桌面程序，适用于课程查询、整理待抢课程以及轮询或定时抢课。目前不支持体育课。

## 主要功能

- 扫码登录教务系统，自动匹配本机 Chrome 对应的浏览器驱动。
- 按课程代码或课程名称查询素质扩展课、专业扩展课、MOOC 和必修课。
- 为待抢课程设置优先级，并保存当前课程草稿。
- 支持立即轮询和定时抢课，可设置选到一门后停止、满课持续重试。
- 将常用课程组合保存为带名称和备注的抢课列表。
- 支持多个账号，各账号的登录状态、课程、列表和抢课任务互相独立。

## 运行环境

- Windows
- Python 3.12
- Chrome 浏览器

安装依赖：

```bash
pip install orjson requests selenium==4.35.0 pillow beautifulsoup4
```

启动程序：

```bash
python USTB-courseHelper.py
```

## 使用流程

### 1. 扫码登录

程序启动后会在后台准备 ChromeDriver，登录页会持续显示“浏览器驱动准备中...”。首次准备可能需要下载驱动，请保持网络畅通。

准备完成后程序会自动打开登录浏览器，并在页面中央显示二维码。使用手机扫码完成登录后，会直接进入“抢课任务”页。二维码失效或生成失败时，可以点击“重新生成二维码”。

已有账号也可以在自动登录开始前选择“暂不登录，离线进入”。离线状态可以整理课程草稿和命名列表，但不能查询课程或启动抢课。

### 2. 查询课程

进入“课程查询”页，至少填写课程代码或课程名称中的一项，然后点击“查询课程”。学年学期会根据当前日期自动填写，也可以手动修改。

课程类型默认选择“所有”。程序会依次尝试查询以下类型，并汇总去重后的结果：

- 素质扩展课
- 专业扩展课
- MOOC
- 必修课

每一种类型都会自动继续翻页，直到取完该类型的结果；页面会显示各类型找到的课程数量。如果某一种类型查询失败，其他类型仍会继续查询并汇总。

### 3. 添加待抢课程

在查询结果中选择一门或多门课程，设置优先级后点击“添加选中课程”。添加成功后会继续停留在查询页，方便继续搜索和添加。

优先级规则：

- 数字越小，越先尝试。
- 优先级相同时，按照待抢列表中的顺序执行。

可以前往“抢课任务”页查看或删除已经添加的课程。

### 4. 配置并启动抢课

在“抢课任务”页选择运行方式和策略：

- `轮询模式`：点击开始后立即持续尝试。
- `定时抢课`：等待到设定时间后开始持续尝试；如果设定时间已经到达或超过，会立即开始。
- `选到一门后停止`：任意课程成功后结束当前任务。
- `持续重试`：课程已满时继续保留并重试。

确认待抢课程和设置后点击“开始轮询”或对应的开始按钮。待抢课程表会逐门显示当前正在请求的课程、尝试次数和最近一次完整返回；对外容量已满、总容量已满会统一归为“课程容量已满”，上课时间冲突会归为“不符合选课要求”。运行期间可以点击“停止抢课”。

## 命名抢课列表

“抢课任务”页中的“默认列表”会自动保存当前待抢课程，不需要手动保存。需要额外保留某个课程组合时，可以点击“保存列表”，为它填写名称和备注。

通过“管理列表”可以加载、重命名、编辑或删除已保存列表。加载列表会替换当前草稿，程序会在操作前要求确认。不同账号只能看到自己的草稿和列表。

## 多账号使用

大多数单账号用户不需要额外设置。需要添加其他账号时，打开顶部“账号”菜单，选择“添加其他账号”，填写便于识别的名称并扫码登录。

存在多个账号后，可以从账号菜单切换当前账号。其他账号正在运行的抢课任务不会因切换账号或关闭账号管理窗口而停止。扫码登录同一时刻只能进行一个，但登录完成后多个账号的抢课任务可以同时运行。

## 数据与日志

- 账号档案、课程草稿和命名列表保存在项目目录的 `user_data/` 中。
- 登录 Cookie 只在本次程序运行期间保存在内存中，关闭程序后需要重新登录。
- 运行日志保存在 `logs/` 目录，按日期生成文件。

## 常见问题

### 一直显示“浏览器驱动准备中...”

首次运行或 Chrome 更新后，Selenium Manager 可能需要下载匹配的 ChromeDriver。请确认 Chrome 已安装，并检查网络、代理以及 Chrome for Testing 下载源是否可访问。

### “所有”类型没有返回完整结果

程序会分别查询全部四种课程类型，并自动获取后续页面，再将结果去重汇总。页面会显示各类型的课程数量；如果某一类请求失败，也会明确提示，可以稍后重新查询。

### 无法查询课程或开始抢课

请确认当前账号已经扫码登录。离线进入只能编辑草稿和命名列表，不能访问在线课程接口。

### 二维码失效

点击“重新生成二维码”。旧二维码会被清除，新的扫码流程会重新开始。

## 使用限制

- 暂不支持体育课查询和抢课。
- 当前仅提供源码运行方式，没有预打包安装程序。
- 请合理使用查询和轮询功能，并自行确认学校相关规定。
